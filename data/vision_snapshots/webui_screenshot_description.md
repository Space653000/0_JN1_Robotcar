# WebUI 界面演示說明

## 屏幕佈局

### 頭部 (Header)
```
🤖 JN1 機器車               [● 語音] [● 視覺] [● 大腦]
```
- 左：機器車品牌
- 右：3個服務狀態指示燈（綠 = 線上，灰 = 離線）

### 主內容區 (Main Content)

#### 1. 即時畫面 (📹 即時畫面)
```
┌─────────────────────────────┐
│  [相機直播畫面 640x480 JPEG]  │
│  (每 1-2 秒自動更新)         │
└─────────────────────────────┘
```

#### 2. 偵測結果 (👁️ 偵測結果)
```
┌─────────────────────────────┐
│ [人×1] [物體] [未知]  [重新掃描] │
│                             │
└─────────────────────────────┘
```
- 顯示檢測到的物體標籤
- 自動去重並計數
- 「重新掃描」按鈕手動觸發更新

#### 3. 對話區 (💬 對話)
```
┌─────────────────────────────┐
│ [機器回覆消息1]              │
│                 [用戶消息1]  │
│ [機器回覆消息2]              │
│                 [用戶消息2]  │
├─────────────────────────────┤
│ [輸入框: 輸入指令...]  [送出]  │
└─────────────────────────────┘
```
- 上部分：對話歷史（藍 = 機器，綠 = 用戶）
- 下部分：輸入框 + 送出按鈕

## 響應式設計

### 手機豎屏 (320px-768px)
- 單欄布局
- 字體縮小
- 按鈕易點擊（≥44px 高度）
- 防 iOS 自動放大

### 平板/桌面 (>768px)
- 多欄可選（未來擴展）
- 原始字體大小

## 色彩方案

| 元素 | 顏色 | 用途 |
|-----|------|------|
| 背景 | #1a1a1a | 深色護眼 |
| 文字 | #e0e0e0 | 高對比 |
| 在線指示 | #4ade80 | 綠色 (成功) |
| 用戶消息 | #4ade80 | 綠色文本 |
| 機器消息 | #60a5fa | 藍色文本 |
| 按鈕 | #1e40af | 深藍 |

## 技術細節

### 前端架構
- 無框架 (Vanilla JavaScript)
- 即時 API 呼叫
- WebSocket 可選（未來）

### API 端點
```
GET  /api/health              → 各服務健康檢查
GET  /api/frame               → JPEG 圖像流
GET  /api/perception/state    → 偵測結果 JSON
POST /api/ask                 → 對話請求
```

### 更新週期
- 健康檢查：5 秒
- 相機畫面：1.5 秒
- 偵測結果：10 秒（可手動觸發）

## 使用流程

1. **連線** → 手機開啟 `http://<IP>:8080`
2. **監看** → 實時看相機和偵測
3. **對話** → 輸入文本下指令
4. **狀態** → 看頭部 3 個綠點確認服務在線
